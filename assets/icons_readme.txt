X86MSX 아이콘 폴더 (Icons)
==========================

X86MSX가 화면에 그리는 아이콘·배지 그림이 모두 이 폴더에 있습니다.
같은 이름의 PNG로 바꿔 넣으면 다음에 켤 때 그 그림이 나옵니다.
파일을 지우면 X86MSX 본체에 든 기본 그림을 씁니다.

그림 규칙
  - PNG, 투명 배경. 아이콘은 64x64까지 (48x48 권장), 배지는 512x96까지.
  - 색이 있는 그림은 그대로 그립니다 (장치가 꺼져 있으면 흐리게).
  - 검정·회색만 있는 그림은 "모양"으로 보고 상태 색(꺼짐 회색, 켜짐 흰색 등)으로 칠합니다.
  - POINTER.png는 왼쪽 위 끝이 가리키는 점입니다.

------------------------------------------------------------------
X86MSX icon folder: every icon and badge X86MSX draws is here.
Replace a file with your own PNG of the same name (transparent background,
icons up to 64x64 - 48x48 recommended, badges up to 512x96).
Colour pictures are drawn as they are (dimmed when the device is off);
black/grey pictures are used as a shape and painted in the status colour.
Delete a file to use the built-in picture.
