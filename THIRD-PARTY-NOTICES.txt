2. HARDWARE SPECIFICATIONS
--------------------------------------------------------------------------------

The emulation of the following hardware was implemented independently, based on
publicly available documentation and technical specifications. No third-party
source code is included.

  * Yamaha V9990 video processor (Gfx9000 cartridge)
  * Zilog Z80 CPU
  * ASCII R800 CPU
  * PSG (AY-3-8910 / YM2149 compatible)
  * MSX-MUSIC (YM2413 compatible FM sound)
  * PCM
  * MSX-MIDI interface
  * MSX slot / memory-mapper architecture
