# X86MSX

운영체제 없이 PC에서 바로 부팅해서 돌아가는 MSX 에뮬레이터입니다.
USB 메모리에 넣고 부팅하면 윈도우도 리눅스도 거치지 않고 MSX 화면이 바로 뜹니다.

- 만든이: KimTaeWoo
- 도와준이: Lee.J.H

## 왜 만들었나

작년부터 의문이 있었습니다.

조금 지난 1~4세대 컴퓨터에서 운영체제 없이 MSX 시스템을 에뮬할 수 있을까?
왜 에뮬레이터는 운영체제 위에서, 아니면 FPGA에서만 만들 생각을 할까?
어차피 같은 에뮬인데.

그래서 작년부터 어셈블러와 C로 코딩할 생각을 했습니다.
이미 잘 만들어진 칩들의 소스와 BIOS를 모으기 시작했고,
어셈블러로 첫 화면까지 열심히 코딩했습니다. 짬짬이 하는 일이라 옵션도 기능도 없이
BASIC 첫 화면만 봤습니다.

그런데 한순간에 올스톱했습니다.
뭐, 80년대 프로그래머가 하는 짓이 그렇지 하면서 왜 만들게 되었는지 적어 둡니다.

## 지금까지 만든 내역

1. **호스트 시험 단계.** 일반 PC에서 Z80 코어(ZEXALL/ZEXDOC 통과), TMS9918A, PPI, PSG를 만들어 DPC-200 BIOS로 BASIC `Ok`까지 확인했습니다.
2. **베어메탈 부팅.** 2단계 로더로 USB에서 바로 부팅하고, 보호 모드로 들어가 VBE 화면에 그립니다. 이어서 UEFI 부팅(`BOOTX64.EFI`)을 붙였습니다.
3. **MSX2 / 2+ / turbo R.** V9938·V9958·V9990, R800, 확장 슬롯, 여러 카트리지 매퍼를 붙였습니다.
4. **소리.** PSG, FM, SCC, MoonSound, MIDI(MT-32, SC-55, SoundFont)를 만들었고 PC의 HD Audio로 내보냅니다.
5. **저장 장치.** 디스크 이미지, zip 안의 디스크, Nextor 하드 디스크를 지원합니다.
6. **네트워크.** 유선·무선 LAN과 UNAPI 네트워크 카트리지를 붙였습니다.
7. **화면과 사용성.** 키보드 중심 메뉴, 키 편집기, 상태 저장, 여러 글꼴, 한국어를 포함한 여러 언어를 넣었습니다.
8. **구조 정리.** 코어를 고정하고 장치를 끼워 넣는 구조로 바꾸고, Z80/R800 코어를 어셈블리로 옮기는 작업을 단계별로 시험하며 진행 중입니다.

현재 버전은 5.3.5입니다. 여러 대의 실제 PC(4세대부터 최신 세대까지의 노트북·데스크톱)에서 직접 시험하며 고치고 있습니다.

## 특징

- **운영체제 없이 부팅.** UEFI 전용 PC와 옛 BIOS(CSM) PC 모두에서 USB로 부팅합니다.
- **여러 기종.** blueMSX의 `config.ini`와 Machines 폴더 구조를 그대로 읽어서 MSX1 / MSX2 / MSX2+ / turbo R 기종을 고를 수 있습니다. 처음 부팅은 C-BIOS 기종입니다.
- **Z80 · R800.** Z80 코어는 ZEXALL/ZEXDOC를 통과하고, 타이밍 시험도 함께 돌립니다.
- **소리.** 소리 칩과 MIDI 기기를 따로따로 독립된 장치로 다룹니다. MT-32나 SC-55를 두 대씩 꽂을 수도 있습니다.
- **카트리지와 디스크.** 일반 ROM, ASCII8/16, Konami, SCC 등 여러 매퍼, 특수 카트리지, 디스크, zip, Nextor.
- **네트워크.** 유선(DHCP) · 무선 LAN, MSX에서 쓰는 UNAPI 방식.
- **조작.** 모든 메뉴가 키보드로 되고, 키 배치를 직접 편집할 수 있습니다. 창은 필요한 만큼만 따로 엽니다.
- **자동 시험.** `make test`(단위·장치 시험)와 `make regress`(실제 기종 부팅 회귀)로 고칠 때마다 확인합니다. 실제 PC에서 잘 되던 동작은 바꾸지 않는 것을 원칙으로 합니다.

## 만들고 시험하기

```sh
make test       # 단위 시험
make regress    # 기종 부팅 회귀 시험 (ROM 필요)
make image      # build/msx1.img 부팅 USB 이미지
```

## ROM에 대해서

상용 BIOS ROM과 게임은 이 저장소에 넣지 않았습니다. 기본으로 들어 있는 것은 자유롭게 쓸 수 있는 C-BIOS뿐입니다.
다른 기종을 쓰려면 본인이 가진 ROM을 BlueMSX의 방식으로  `Machines` 폴더에 넣어 주세요.
